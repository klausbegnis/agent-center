# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The full text at that address is the standard everyone taking part is held to.

## In short

- Be kind and assume good intent. Critique the change, never the person.
- No harassment, insults, sexualised language or attention, or publishing someone's private
  information.
- Maintainers will remove, edit or reject comments, commits, issues and pull requests that
  break this, and may ban someone for repeated or serious breaches.

## Scope

It applies in the repository's issues, pull requests and discussions, and anywhere someone is
representing the project.

## Reporting

Report unacceptable behaviour privately, not in a public issue. Use GitHub's "Report content"
on the comment, issue or pull request, or the repository's private reporting form (Security,
then "Report a vulnerability") and say it is a conduct report. If neither is there, open an issue
titled "Conduct contact wanted" with no details, and a maintainer will answer with a private way
to continue. Reports are kept confidential
and reviewed promptly.
